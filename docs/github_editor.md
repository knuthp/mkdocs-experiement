# Github editor AI

!!! warning
    Do not share company internal information or sensitive data with the AI, as it may be processed by external servers.

GitHub editor AI is a feature that allows you to use AI to assist with code editing tasks directly within the GitHub interface. It can help with code suggestions, error detection, and even writing new code based on your prompts.

This page provides a brief overview of how to use the GitHub editor AI feature in `Visual Studio Code for the Web`. My plan is to get help writing pages to be shared on GitHub/Confluence, and to use the AI to help with code suggestions and completions.


## How to use GitHub editor AI
1. **Open a Repository**: Navigate to the repository you want to work on in GitHub.
2. **Open the Editor**: Click on the `Code` tab, then select `Open in Visual Studio Code for the Web` to launch the editor.
3. **Enable AI Features**: If the AI features are not enabled by default, you have to install the GitHub Copilot extension from the Visual Studio Code marketplace.
4. **Start Coding**: Begin typing your code. The AI will provide suggestions and completions based on the context of your code.

## Key takeaways
- Once enabled, the AI will automatically suggest code completions as you type.
- You can accept suggestions by pressing `Tab` or `Enter`.
- The AI can also help with writing documentation, comments, and other text-based content.
